goldpan.adapters.midas¶

The MIDAS adapter: raw SuperCDMS SNOLAB DAQ files (.mid, .mid.gz, .mid.lz4) into an Events. Read only.

A file is a sequence of MIDAS events. The first (id 0x8000, begin of run) carries the ODB, the experiment’s settings, as XML; the last (id 0x8001, end of run) carries it again; each event in between (id 1) holds a bank SCD0 with one trigger in the SNOLAB data format (the CDMS I/O library, CDMSIOLIB::pack_event; this reader follows unpack_event, format versions 4 to 8) and sometimes a veto bank LDV0. Polling-cycle events (trigger type 8) and events of other detectors carry no traces and are skipped. The format is described at https://gitlab.com/supercdms/DAQ/IOLibrary (README, “Description of Data Structures”).

Like the idx adapter, this one does not know your detector: you say which detector number and which channel numbers are the named channels, and you name the readout, which is checked against the sample rate in the file:

from goldpan.adapters import midas
from goldpan.config import Z7
ev = midas.read("24260424_145101_F0001.mid.lz4", detector_name="Z7", detector_id=7, config=Z7, max_events=100,
                channels={"PAS1": 0, "PAS2": 1, "PBS1": 2})              # channel name -> channel number

  • channels are phonon channels (channel_type=1; pass channel_type=0 for charge). The traces keep the file’s uint16.

  • Only the channels you name are copied; the others are read past, so a 15 GB file costs a pass over it. Use max_events= to stop early, or iter_chunks to process a file in pieces.

  • Event quantities: series and dump (from a file name like <series>_F0003.mid.lz4, or series=/dump=), event (the event number), trigger_id, trigger_type (as text: “Physics”, “BeginOfRunRandom”, …), readout_type and global_timestamp.

  • meta: run (run number, state, start and stop time from the ODB), complete (the end-of-run event was seen: a file cut short is not complete), skipped_events, format_version, source.

  • Hybrid sampling (pre- or post-pulse samples at a coarser rate) is not read yet: such a file raises NotImplementedError.

.mid.lz4 files need the lz4 package (pip install lz4); .mid.gz and plain .mid need nothing.

goldpan.adapters.midas.parse_odb(xml)[source]¶

The run information of an ODB (XML bytes of a begin- or end-of-run event), from its /Runinfo directory: run_number, state (as stored; the real begin- and end-of-run dumps show 1 and 3), start_time and stop_time (unix seconds; 0 while running). Keys that are not found are left out; the rest of the ODB (tens of megabytes) is not parsed.

Return type:

dict

goldpan.adapters.midas.unpack_scd0(data, want=None, channel_type=1)[source]¶

The trigger in the SCD0 bank of a MIDAS data event.

Returns dict(format_version, trigger_id, event_number, trigger_type, readout_type, global_timestamp, detectors) where detectors maps a detector number to {channel_number: dict(rate_khz, downsampling, pretrigger, pre, on, post, data)}. want ({detector: {channel numbers}}) keeps the waveforms of those channels of type channel_type only (the others are read past); None keeps every channel. Returns None for an event without an SCD0 bank.

Parameters:

  • data (bytes)

  • want (Mapping | None)

  • channel_type (int)

dict
