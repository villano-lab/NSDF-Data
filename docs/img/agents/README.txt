Icons used on agents.html and the front page.

claude, claudecode, googlegemini, perplexity, cursor, github, githubcopilot: from Simple Icons
(https://simpleicons.org), version 16.34.0, released under CC0. The brands and logos belong to their owners
(Anthropic, Google, Perplexity, Anysphere, GitHub); they are shown only to identify the service a link opens.

chat, terminal, assistant: simple symbols drawn for this project. They stand in where the open icon set has no
logo (OpenAI/ChatGPT and Codex, Microsoft Copilot, Visual Studio Code).

The icons are drawn as masks in docs/style.css, so each takes a color from the page and works in dark mode.
