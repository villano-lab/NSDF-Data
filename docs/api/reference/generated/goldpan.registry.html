goldpan.registry¶

A registry of the facts about an experiment that analysis needs and the library must not contain: the readouts (how a pretrigger window, a glitch and a sample period are set), and the detectors (their number, type, readout and where each named channel is wired in a given file format).

This module is the mechanism only. No detector of any experiment is written in goldpan; the records are data and live outside the package, in folders of TOML files (for the Run 76 detector of this project, the registry/ folder of the repository, which is laid out so it can become a repository of its own). The readout presets DCRC_RUN76 and Z7 of goldpan.config are older and stay where they are; a registry may define readouts too, and a name is looked up in the registry first and then among those presets. A registry is built from sources; a folder of TOML files is the first kind, and anything with a load() method that yields (origin, tables) pairs can take its place later (a Git repository, a database) without a change anywhere else:

from goldpan import registry

reg = registry.load("~/NSDF-Data/registry")        # one or more folders; the environment variable GOLDPAN_REGISTRY is added
reg.readout_config("DCRC_RUN76")                   # a goldpan.config.PulseConfig (a preset, or the registry's own readout)
reg.detector("NAI-S2").number                      # 1
reg.detector("NAI-S2").read_defaults("idx")        # {'channels': {...}, 'roles': {...}}: the defaults of [sources.read]

A dataset definition file names the folders in [dataset] registry = [...] (see goldpan.dataset), and a source whose detector is a name in the registry takes its readout, its channels and its roles from there. Anything written in the definition file itself wins over the registry, key by key.

The files. Any file *.toml of a folder (sorted by name); every file holds the tables readouts and detectors, and the integer format_version (1):

format_version = 1

[readouts.DCRC_RUN76]
pretrigger_samples = 500
glitch_samples = 10
sample_period_s = 0.8e-6
status = "inferred"                                # "confirmed" or "inferred": required
evidence = "where the numbers come from"           # required: what a reader needs to judge the entry

[detectors."NAI-S2"]
number = 1                                         # the N of zip<N> in RQ files, the detector number of the MIDAS ODB
readout = "DCRC_RUN76"
status = "inferred"
evidence = "..."
[detectors."NAI-S2".idx]                           # defaults for [sources.read] of a source of this format
channels = { Side2pC = [0, 0] }

Readouts take pretrigger_samples, glitch_samples, sample_period_s (all three: nothing is assumed), status, evidence, description and series; detectors take number, type_code, tower, plane, odb_name, readout, status, evidence, description and series, plus one table per file format. Unknown keys are errors, as in the dataset definition file, and a name defined twice (in two files or two sources) is an error, so two folders can never disagree silently.
