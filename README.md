# NSDF-Data
Code to work with the National Science Data Fabric and its online API to University of Minnesota R68/R76 SuperCDMS-type data.

To get started, go to: https://nsdf-fabric.github.io/nsdf-slac/ 

**All data analysis goes in [`data_analysis/`](data_analysis/README.md), and nowhere else.** The rest of this repository is the shared library (`python/`), the guides and notes (`docs/`, `notes/`) and the tools that build them. A CI check fails a pull request that adds a notebook outside `data_analysis/`.

Analysis notes (progress summaries, one per investigation): https://villano-lab.github.io/NSDF-Data/
