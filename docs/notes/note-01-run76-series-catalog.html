Run76 series catalog: non-PuBe series and availability on nsdf-cli

Note 1 · Author(s): Anthony Villano · 14 Sept 2026 · Status: Complete (2026-09-14)

Code Repository

Files this note rests on, each pinned to the commit that last changed it:

  • R76/DataSeriesList.xlsx — the run log; sheet Run76 is the one used here. Pinned to 8917088.
  • R76/am_lead_series.csv — 317 Am/lead series (see below; despite living under R76/ it covers Runs 72–74). Pinned to c892af4.
  • nsdf_dark_matter_cli/r_dataset.csv — the manifest bundled inside the installed nsdf-cli package (78,088 files, each tagged R68 or R76). Not in this repository.

Question

Which Run76 data other than PuBe (in particular Am) exists, and can it be downloaded with nsdf-cli?

Result: only PuBe is downloadable

The Run76 sheet lists 235 series. Each series was matched by its series name against the file names in the bundled manifest, counting it as available if any file with that series name is tagged R76.

The manifest contains exactly 130 series tagged R76, and all 130 are PuBe series. None of the 65 non-PuBe Run76 series are in it.

The 42 Am series split by shielding as: 21 “Am / Pb&poly E&W only”, 19 “Am / Pb&poly, lead stack, borax”, 1 “Am / Pb&poly except N”, and 1 “Am / Pb&poly, lead stack”.

Lesson: read column C, and mind the filter. The Am tag lives in column C (source / shield) of the run-log sheets, not in the type column, and the sheet carries an Excel AutoFilter that hides rows. A first pass that read type missed the Am series entirely; the numbers above come from reading column C directly with the filter ignored.

Am/lead series in Runs 72–74

R76/am_lead_series.csv lists the series tagged Am/lead in the neighbouring runs: 317 series (Run72: 8, Run73: 175, Run74: 134). None of them are available on nsdf-cli (0 files each). This is a different set from the 42 Run76 Am series above, and it does not include any Run76 series.

Status / Next Steps

  • Complete for the question asked: there is no non-PuBe Run76 data reachable through nsdf-cli. All analysis so far therefore uses PuBe series (notably 07221203_2025).
  • The manifest is the one bundled with the installed package; re-run the check after upgrading nsdf-cli, since new series may be added.
  • If Am or Na-22 data are needed, they would have to come from outside nsdf-cli or be added to the manifest.
  • The 42-series Run76 Am list is not saved as a file in the repository; only the Runs 72–74 list is.
