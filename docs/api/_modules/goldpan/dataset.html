Source code for goldpan.dataset

"""A dataset definition: which raw files, how to read them, and which processing to run on them. One TOML file, read by both
packages: `goldsluice` runs the processing in batch, `goldpan` reads the pulses and the processed quantities back.

The file (`r76.dataset.toml`)::

    [dataset]
    name = "r76-nai"
    output = "r76-nai"                      # the processed quantities: a goldpan Parquet dataset (directory), keep it outside the repository
    # output_format = "root"                # optional: RQ-style ROOT files instead, with our names (needs root_detector = N too)
    # registry = ["../registry"]            # optional: folders of detector records (goldpan.registry), relative to this file
    # metadata = "r76.series.csv"           # optional: run metadata per series (high voltage, trigger setting, ...), joined to the events when read

    [[sources]]                             # where the pulses come from; as many as you like
    name = "side2"
    format = "idx"                          # any adapter: idx, midas, parquet, or one you registered
    paths = ["~/idx/07221203_2025_F0001"]   # raw files or dump folders ...
    glob = "~/idx/07221203_2025_F*"         # ... and/or a pattern (sorted)
    detector = "NAI-S2"                     # the detector name (the adapter's detector_name)
    readout = "DCRC_RUN76"                  # a preset of goldpan.config, or { pretrigger_samples = 1000, glitch_samples = 10, sample_period_s = 0.8e-6 }
    [sources.read]                          # the other keyword arguments of the adapter's read(), verbatim
    channels = { Side2pA = [0, 0], Side2pB = [0, 1] }
    roles = { Side2pA = "phonon", Side2pB = "phonon" }

    [[processing]]                          # the steps, in order; each adds quantities to the channels it names
    algorithm = "peak"                      # a goldsluice algorithm
    channels = "role:phonon"                # "all", "role:<role>", or a list of channel names
    [processing.params]
    glitch_samples = "@readout.glitch_samples"        # "@readout.<field>": taken from the readout of the data
    pretrigger_samples = "@readout.pretrigger_samples"
    amps_per_adc = 1.5e-9

**Where the output goes.** `output` may be a full path (`"C:/data/goldsluice-output/r76-nai"`, or `"~/goldsluice-output/r76-nai"`), which is used as
written. A *relative* `output` (`"r76-nai"`) is put under the folder named by the environment variable `GOLDSLUICE_OUTPUT` when it is set, so the
definition holds no path of your machine and the same file runs on every computer; when it is not set, a relative `output` is relative to the
folder of the definition file, as before (and `goldsluice run` refuses it if that is inside a repository that does not ignore it).

**An unfinished run.** `goldsluice run` writes `_goldsluice_status.json` into the output folder (`STATUS_FILE`): ``{"state": "running", ...}``
when it starts and ``{"state": "complete", "started": ..., "finished": ..., "files": N, ...}`` when every raw file of the definition has been processed.
If a run stops (an error, Ctrl-C, a crash) the state stays `running`, and `Dataset.processed()` warns that the output may be incomplete. An output
folder made before this file existed has none and is read without a warning.

**Steps that build on each other.** A step reads the raw trace unless it has an `input`. A step whose algorithm gives a trace (a filter or a
baseline subtraction: `goldsluice algorithms` lists them) has a `name`, writes no quantities, and a later step with `input = "<name>"`
reads its result instead of the raw trace, for the channels the two steps share. A `suffix` is appended to the names of the quantities
of a step, so that the same algorithm can run on both (`adc_max`, and `adc_max_lp` from the filtered trace). The quantities of a step must
still be written once: two steps giving the same name is an error. Steps run in the order written, and an `input` is a step above::

    [[processing]]
    algorithm = "lowpass"                   # a filter: gives a trace, so it has a name
    name = "lp"
    channels = "role:phonon"
    [processing.params]
    cutoff_hz = 50e3
    order = 4
    sample_period_s = "@readout.sample_period_s"

    [[processing]]
    algorithm = "peak"
    channels = "role:phonon"
    input = "lp"                            # the peak of the filtered trace
    suffix = "_lp"                          # adc_max_lp, current_max_lp
    [processing.params]
    ...

**Different steps for different sources.** Every step runs on every source unless it has `sources`, a list of source names. Use it when the
detectors need different processing; a step on `role:phonon` already adapts to each detector's own channels, so name sources only when the steps differ.
A step that reads a filter (`input`) must run on a subset of the sources the filter runs on, and every source needs at least one step. A source's output is
redone only when the steps that run on it change. Read back together, the sources show their different quantities as records of different
fields (an awkward union), so pick one source's rows by `series` before you use its fields::

    [[sources]]
    name = "nai"
    detector = "NAI-S2"
    ...
    [[sources]]
    name = "ge"
    detector = "GE-1"
    ...
    [[processing]]
    algorithm = "peak"
    channels = "role:phonon"                # no `sources`: runs on both
    ...
    [[processing]]
    algorithm = "rise_crossing"
    channels = "role:phonon"
    sources = ["ge"]                        # only the raw files of the source "ge"
    ...

**Run metadata.** `metadata` is a reference to facts about whole series that an analysis needs for every event (high voltage, trigger setting,
...): today a CSV file with a `series` column and any other columns (`hv_v`, `trigger_value`, `trigger`, ...), relative to this file, one row per series;
later it may name a database instead, and nothing else in the file changes. The values are **joined at read time**: `Dataset.processed()` (and so
`read()`) adds one column per column of the table to the events, taken from the row of their series, so a change of a value never needs the data to be
processed again. Nothing is written into the output and the fingerprint does not change. A series that has events but is not listed is an error that
names it, and so is a column named like a quantity or a channel (`processed(metadata=False)` skips the join). The table is also at
`spec.run_metadata()`, and `goldpan.runmeta` joins and groups it for events you have already. ROOT output is not read by `processed()`, so it has no metadata.

**Writing a definition.** `dump(definition, path)` writes a definition file from a mapping with the layout of the file (the same thing `tomllib` gives
for it, so a program, such as a form in a browser, can build it from what the user chose) or from a `DatasetSpec`; `dumps` gives the text. It
checks the definition the way `load` does before it writes anything, so a file it writes always loads, and `load` of it gives back the same
definition. Comments are not kept and nothing is added, so write `format_version` yourself if the file should say which format it uses.

Nothing is assumed: the readout, the channels and every algorithm parameter are written down, in the file or in a registry it names.
With `registry` (and/or the environment variable `GOLDPAN_REGISTRY`), a source whose `detector` is a name in the registry takes the
readout, the `[sources.read]` defaults of its file format and, for ROOT output, `root_detector` from the detector's record
(`goldpan.registry`); whatever the file itself states wins, key by key, and a readout that disagrees with the registry's is a warning.
A detector name that is not in any registry is only a label, as before. `Dataset.open(path)` gives the same file to both packages::

    ds = Dataset.open("r76.dataset.toml")
    ev = ds.read()                          # the pulses, with the processed quantities attached (one Events)
    q = ds.processed()                      # only the processed quantities, no pulses: small and fast
    ev.quantities["Side2pA"]["current_max"]

With `output_format = "root"` the quantities are written as ROOT files in the layout of the collaboration's RQ files (`rqDir/eventTree`
and `rqDir/zip<N>`, see `goldpan.adapters.rq_root.write`), under our names (`Side2pA_adc_max`); `root_detector` is that `N`. Read them with
`goldpan.adapters.rq_root.read`: `Dataset.processed()` reads the Parquet output only.

The processed quantities are stored one record per channel (`quantities["Side2pA"]["adc_max"]`), keyed by `series`, `dump`,
`event`. `python -m goldsluice run <file>` produces them; reading them before that raises an error that says so.

FORMAT_VERSION = 7
"""The version of the dataset definition file; a reader refuses a newer one. 2: `output_format` and `root_detector`. 3: `registry`
(and a detector named in a registry supplies readout, `[sources.read]` defaults and `root_detector`). 4: a relative `output` goes
under `$GOLDSLUICE_OUTPUT` when that is set. 5: `metadata`, a reference (a CSV file) to run metadata per series, joined to the events when they are read.
6: steps may have a `name`, an `input` (the `name` of an earlier step whose result they read) and a `suffix` for their quantities.
7: a step may have `sources`, the names of the sources it applies to (without it a step applies to all of them)."""

STATUS_FILE = "_goldsluice_status.json"
"""The file in an output folder that says whether the last `goldsluice run` finished (see `output_status`)."""

ENV_OUTPUT = "GOLDSLUICE_OUTPUT"
"""The environment variable that holds the folder under which a relative `output` of a definition is placed."""

_TOP = {"dataset", "sources", "processing"}
_DATASET = {"name", "output", "description", "format_version", "output_format", "root_detector", "registry", "metadata"}

    def files(self) -> list:
        """The raw files or dump folders of the source, in order. `ValueError` if a pattern or path matches nothing."""
        out = []
        for pattern in self.patterns:
            expanded = Path(pattern).expanduser()
            expanded = expanded if expanded.is_absolute() else self.base / expanded
            if any(ch in pattern for ch in "*?["):
                found = sorted(_glob.glob(str(expanded)))
            else:
                found = [str(expanded)] if expanded.exists() else []
            if not found:
                raise ValueError(f"source {self.name!r}: {pattern!r} matches nothing (looked in {self.base})")
            out.extend(Path(f) for f in found)
        return out

    def applies_to(self, source_name: str) -> bool:
        """Does this step run on the raw files of the source called `source_name`? (Always, unless the step names its `sources`.)"""

    def channel_names(self, detector) -> list:
        """The channels of `detector` this step applies to."""
        if self.channels == "all":
            return detector.channel_names()
        if isinstance(self.channels, str):
            names = detector.channels_with_role(self.channels[len("role:"):])
            if not names:
                raise ValueError(f"step {self.algorithm!r}: the detector {detector.name!r} has no channel with role "
                                 f"{self.channels[len('role:'):]!r} (roles: {sorted({c.role for c in detector.channels})})")
            return names
        for name in self.channels:
            detector.channel(name)                                     # KeyError for an unknown channel
        return list(self.channels)

    def resolve(self, config: PulseConfig) -> dict:
        """The parameters with every `"@readout.<field>"` replaced by that field of `config`."""
        out = {}
        for key, value in self.params.items():
            if isinstance(value, str) and value.startswith("@readout."):
                field = value[len("@readout."):]
                if field not in _READOUT:
                    raise ValueError(f"step {self.algorithm!r}, parameter {key!r}: {value!r}: the readout has {sorted(_READOUT)}")
                value = getattr(config, field)
                if value is None:
                    raise ValueError(f"step {self.algorithm!r}, parameter {key!r}: the readout does not give {field}")
            out[key] = value
        return out

    def source(self, name: Optional[str] = None) -> Source:
        if name is None:
            if len(self.sources) != 1:
                raise ValueError(f"the dataset has several sources {[s.name for s in self.sources]}: name one")
            return self.sources[0]
        for s in self.sources:
            if s.name == name:
                return s
        raise KeyError(f"no source {name!r}; the dataset has {[s.name for s in self.sources]}")






def _unknown(where: str, table: Mapping, allowed: set) -> None:
    extra = sorted(set(table) - allowed)
    if extra:
        raise ValueError(f"{where}: unknown key(s) {extra}; allowed: {sorted(allowed)}")


def _readout(value, where: str, reg: _registry.Registry) -> Optional[PulseConfig]:
    if value is None:
        return None
    if isinstance(value, str):
        try:
            return reg.readout_config(value)
        except KeyError as e:
            raise ValueError(f"{where}: readout {e.args[0]}") from None
    if isinstance(value, Mapping):
        _unknown(f"{where}: readout", value, _READOUT)
        missing = sorted(_READOUT - set(value))
        if missing:
            raise ValueError(f"{where}: readout needs {missing} (there are no defaults); write the three numbers or name a preset")
        return PulseConfig(**value)
    raise ValueError(f"{where}: readout must be a preset name or a table, not {type(value).__name__}")


def _output_path(written: str, base: Path) -> Path:
    """Where `output = written` goes: a full path (or one that starts with ``~``) as written; a relative one under
    ``$GOLDSLUICE_OUTPUT`` when that is set, otherwise relative to the folder `base` of the definition."""
    path = Path(written).expanduser()
    if path.is_absolute():
        return path
    root = os.environ.get(ENV_OUTPUT, "").strip()
    return Path(root).expanduser() / path if root else base / path

@status(DONE)
def load(path) -> DatasetSpec:
    """Read and check a dataset definition file. Nothing is opened: the raw files need not exist yet."""
    path = Path(path).expanduser().resolve()
    try:
        raw = tomllib.loads(path.read_text(encoding="utf-8"))
    except tomllib.TOMLDecodeError as e:
        raise ValueError(f"{path}: not valid TOML: {e}") from None
    return _spec(raw, path)




def _spec(raw: Mapping, path: Path) -> DatasetSpec:
    """Check a parsed definition (`raw`) as if it were the file `path` (which need not exist: only its folder is used) and make the spec."""
    _unknown(str(path), raw, _TOP)
    d = raw.get("dataset")
    if d is None:
        raise ValueError(f"{path}: needs a [dataset] table with name and output")
    _unknown(f"{path}: [dataset]", d, _DATASET)
    if d.get("format_version", FORMAT_VERSION) > FORMAT_VERSION:
        raise ValueError(f"{path} has format_version {d['format_version']}, newer than this goldpan ({FORMAT_VERSION})")
    for key in ("name", "output"):
        if key not in d:
            raise ValueError(f"{path}: [dataset] needs {key!r}")
    base = path.parent
    folders = d.get("registry", [])
    folders = [folders] if isinstance(folders, str) else folders
    if not (isinstance(folders, list) and all(isinstance(f, str) for f in folders)):
        raise ValueError(f"{path}: [dataset] registry must be a folder or a list of folders")
    try:
        reg = _registry.load(*[(Path(f).expanduser() if Path(f).expanduser().is_absolute() else base / Path(f).expanduser())
                               for f in folders])
    except ValueError as e:
        raise ValueError(f"{path}: {e}") from None
    output = _output_path(d["output"], base)
    output_format = d.get("output_format", "parquet")
    if output_format not in _OUTPUT_FORMATS:
        raise ValueError(f"{path}: [dataset] output_format must be one of {list(_OUTPUT_FORMATS)}, not {output_format!r}")
    root_detector = d.get("root_detector")
    if root_detector is not None and (not isinstance(root_detector, int) or isinstance(root_detector, bool) or root_detector < 0):
        raise ValueError(f"{path}: root_detector must be a whole number, the N of the zip<N> tree (output_format = \"root\" needs root_detector = N)")
    if output_format != "root" and root_detector is not None:
        raise ValueError(f"{path}: root_detector only applies with output_format = \"root\"")

    metadata = None
    if "metadata" in d:
        if not isinstance(d["metadata"], str) or not d["metadata"].strip():
            raise ValueError(f"{path}: [dataset] metadata must be the path of a CSV file (relative to this file)")
        metadata = Path(d["metadata"]).expanduser()
        metadata = metadata if metadata.is_absolute() else base / metadata

    sources = []
    for i, s in enumerate(raw.get("sources", [])):
        where = f"{path}: sources[{i}]"
        _unknown(where, s, _SOURCE)
        for key in ("format", "detector"):
            if key not in s:
                raise ValueError(f"{where} needs {key!r}")
        patterns = tuple(list(s.get("paths", [])) + ([s["glob"]] if "glob" in s else []))
        if not patterns:
            raise ValueError(f"{where} needs paths and/or glob")
        record = reg.detector(s["detector"]) if reg.has_detector(s["detector"]) else None
        readout = _readout(s.get("readout"), where, reg)
        read = dict(s.get("read", {}))
        if record is not None:
            if record.readout is not None:
                from_registry = _readout(record.readout, f"{where}: the registry's detector {record.name!r}", reg)
                if readout is None:
                    readout = from_registry
                elif readout != from_registry:
                    warnings.warn(f"{where}: the readout written here ({readout}) is not the one the registry gives detector "
                                  f"{record.name!r} ({record.readout}: {from_registry}); the one written here is used", stacklevel=2)
            read = {**record.read_defaults(s["format"]), **read}
        sources.append(Source(s.get("name", f"source{i}"), s["format"], patterns, s["detector"], readout, read, base, record))
    if not sources:
        raise ValueError(f"{path}: needs at least one [[sources]]")
    if len({s.name for s in sources}) != len(sources):
        raise ValueError(f"{path}: source names must be unique, got {[s.name for s in sources]}")
    if output_format == "root":
        numbers = {s.detector_record.number for s in sources if s.detector_record is not None and s.detector_record.number is not None}
        if root_detector is None:
            if len(numbers) != 1:
                raise ValueError(f"{path}: output_format = \"root\" needs root_detector = N, the number of the zip<N> tree (a whole number), "
                                 "or one detector in a registry that has a `number`" + (f" (the sources have {sorted(numbers)})" if numbers else ""))
            root_detector = next(iter(numbers))
        elif numbers and numbers != {root_detector}:
            warnings.warn(f"{path}: root_detector = {root_detector} is not the number the registry gives the detector "
                          f"({sorted(numbers)}); the one written here is used", stacklevel=2)

    steps = []
    for i, st in enumerate(raw.get("processing", [])):
        where = f"{path}: processing[{i}]"
        _unknown(where, st, _STEP)
        for key in ("algorithm", "channels"):
            if key not in st:
                raise ValueError(f"{where} needs {key!r}")
        channels = st["channels"]
        if isinstance(channels, list):
            channels = tuple(channels)
        elif not (channels == "all" or (isinstance(channels, str) and channels.startswith("role:") and len(channels) > 5)):
            raise ValueError(f"{where}: channels must be \"all\", \"role:<role>\" or a list of names, not {channels!r}")
        name, source, suffix = st.get("name"), st.get("input"), st.get("suffix", "")
        if name is not None and not (isinstance(name, str) and _STEP_NAME.match(name)):
            raise ValueError(f"{where}: name must be letters, digits and underscores, starting with a letter, not {name!r}")
        if name is not None and name in {x.name for x in steps}:
            raise ValueError(f"{where}: two steps are named {name!r}")
        if source is not None and source not in {x.name for x in steps if x.name is not None}:
            raise ValueError(f"{where}: input {source!r} is not the name of an earlier step (steps run in order; an input is a step above this one)")
        if not (isinstance(suffix, str) and _SUFFIX.match(suffix)):
            raise ValueError(f"{where}: suffix must be letters, digits and underscores, not {suffix!r}")
        only = st.get("sources")
        if only is not None:
            names = [s.name for s in sources]
            if not (isinstance(only, list) and only and all(isinstance(n, str) for n in only)):
                raise ValueError(f"{where}: sources must be a non-empty list of source names (the sources of this file are {names})")
            if len(set(only)) != len(only):
                raise ValueError(f"{where}: sources names a source twice: {only}")
            unknown = sorted(set(only) - set(names))
            if unknown:
                raise ValueError(f"{where}: sources {unknown} are not sources of this file (they are {names})")
            only = tuple(only)
        if source is not None:                                   # a step that reads a filter must run where the filter runs
            producer = next(x for x in steps if x.name == source)
            mine, theirs = set(only or [s.name for s in sources]), set(producer.sources or [s.name for s in sources])
            if not mine <= theirs:
                raise ValueError(f"{where}: runs on the sources {sorted(mine)} but the step {source!r} that it reads runs only on {sorted(theirs)}")
        steps.append(Step(st["algorithm"], channels, dict(st.get("params", {})), name, source, suffix, only))
    return DatasetSpec(d["name"], output, tuple(sources), tuple(steps), path, raw, output_format, root_detector, reg, metadata)


_toml_key, _toml_value = _key, _value                                      # the writers of values live in `_toml`


def _toml_table(header: str, table: Mapping, sub: Optional[str] = None) -> list:
    """The lines of one table: `header` (``[dataset]``, ``[[sources]]``), its keys, and the sub-table `sub` (``read``, ``params``) after them."""
    lines = [header]
    lines += [f"{_toml_key(k)} = {_toml_value(v)}" for k, v in table.items() if k != sub]
    if table.get(sub):
        lines += [f"[{header.strip('[]')}.{sub}]"] + [f"{_toml_key(k)} = {_toml_value(v)}" for k, v in table[sub].items()]
    return lines


def _toml_text(raw: Mapping, header: str) -> str:
    blocks = [_toml_table("[dataset]", raw["dataset"])]
    blocks += [_toml_table("[[sources]]", s, "read") for s in raw.get("sources", [])]
    blocks += [_toml_table("[[processing]]", st, "params") for st in raw.get("processing", [])]
    comment = "".join(f"# {line}".rstrip() + "\n" for line in header.splitlines()) + ("\n" if header else "")
    return comment + "\n\n".join("\n".join(b) for b in blocks) + "\n"


def _raw_of(definition) -> Mapping:
    return definition.raw if isinstance(definition, DatasetSpec) else definition

@status(DONE)
def dumps(definition, *, base=".", header: str = "") -> str:
    """The text of a dataset definition file, for `definition`: a mapping with the same layout as the file (``{"dataset": {...}, "sources": [...],
    "processing": [...]}``, what `tomllib` gives for it) or a `DatasetSpec` (its `raw`). The definition is checked first, exactly as
    `load` checks a file, as if the file were in the folder `base` (relative `registry` and `metadata` are looked for there), so text that
    `load` would refuse is never produced, and `load(dump(...))` gives back the same definition. `header` is written as comment lines at the
    top. Keys are written as given and nothing is added, not even `format_version`. Tables go in the order dataset, sources, steps, with
    `read` and `params` as sub-tables; comments of an earlier file are not kept."""
    raw = _raw_of(definition)
    _spec(raw, Path(base).expanduser().resolve() / "definition.dataset.toml")
    return _toml_text(raw, header)

@status(DONE)
def dump(definition, path, *, header: str = "") -> DatasetSpec:
    """Write a dataset definition to the file `path` (see `dumps` for what `definition` is and how it is checked; the check looks at the folder of
    `path`) and return it loaded from there, so the caller has what `load(path)` gives. A definition that does not pass the check is not written,
    and an existing file at `path` is left alone."""
    path = Path(path).expanduser().resolve()
    text = dumps(definition, base=path.parent, header=header)
    path.parent.mkdir(parents=True, exist_ok=True)
    path.write_text(text, encoding="utf-8", newline="\n")
    return load(path)

@status(DONE)
def step_record(step: Step) -> dict:
    """A step as it is hashed and recorded in the provenance: `name`, `input`, `suffix` and `sources` appear only when the step has them, so a
    definition without them keeps the fingerprint it had before the keys existed."""
    out = {"algorithm": step.algorithm, "channels": step.channels, "params": step.params}
    for key in ("name", "input"):
        if getattr(step, key) is not None:
            out[key] = getattr(step, key)
    if step.suffix:
        out["suffix"] = step.suffix
    if step.sources is not None:
        out["sources"] = sorted(step.sources)
    return out

@status(DONE)
def fingerprint(spec: DatasetSpec, source: Source) -> str:
    """A short hash of what determines the processed quantities of `source`: how it is read and the processing steps that run on it (a step
    that names other `sources` does not count). The batch run stores it in every output file and skips a file whose fingerprint has not changed."""
    payload = {"source": {"format": source.format, "detector": source.detector,
                          "readout": None if source.readout is None else asdict(source.readout),
                          "read": source.read},
               "steps": [step_record(s) for s in spec.steps if s.applies_to(source.name)]}      # only the steps that run on this source
    if spec.output_format != "parquet":                    # a Parquet definition keeps the fingerprint it had before the key existed
        payload["output"] = {"format": spec.output_format, "root_detector": spec.root_detector}
    blob = json.dumps(payload, sort_keys=True, default=str)
    return hashlib.sha256(blob.encode("utf-8")).hexdigest()[:16]




def _read_kwargs(module, source: Source) -> dict:
    accepted = set(inspect.signature(module.read).parameters)
    kwargs = dict(source.read)
    if "detector_name" in accepted:
        kwargs["detector_name"] = source.detector
    elif "detector" in accepted:
        kwargs["detector"] = source.detector
    if "config" in accepted:
        if source.readout is None:
            raise ValueError(f"source {source.name!r}: the {source.format!r} adapter needs a readout (a preset name or three numbers)")
        kwargs["config"] = source.readout
    unknown = sorted(set(kwargs) - accepted)
    if unknown:
        raise ValueError(f"source {source.name!r}: the {source.format!r} adapter's read() has no argument {unknown}; it has {sorted(accepted)}")
    return kwargs

@status(DONE)
def read_raw(source: Source, path, *, chunk: Optional[int] = None) -> Iterator[Events]:
    """The pulses of one raw file of `source` as `Events` read by its adapter: one `Events`, or with `chunk` pieces of at most
    that many events when the adapter can (`iter_chunks`; otherwise the whole file is one piece)."""
    module = _adapter(source.format)
    kwargs = _read_kwargs(module, source)
    if chunk and hasattr(module, "iter_chunks"):
        yield from module.iter_chunks(path, chunk=chunk, **kwargs)
    else:
        yield module.read(path, **kwargs)

    def processed(self, *, detector: Optional[str] = None, metadata: bool = True) -> Events:
        """The processed quantities of a detector, without pulses (an `Events` with no traces): one record per event. With the run metadata
        of the definition (`metadata`) each event also gets its series' values as columns, joined now (`metadata=False` leaves them out)."""
        out = self.spec.output
        if self.spec.output_format == "root":
            raise ValueError(f"{self.spec.path}: the output is ROOT files ({out}); read them with "
                             f"goldpan.adapters.rq_root.read(path, detector={self.spec.root_detector}). processed() reads Parquet output only")
        if not (out / _parquet.MANIFEST).exists():
            raise FileNotFoundError(f"nothing processed yet in {out}: run `python -m goldsluice run {self.spec.path}`")
        state = output_status(out)
        if state is not None and state.get("state") != "complete":
            warnings.warn(f"{out}: the last `goldsluice run` did not finish (state {state.get('state')!r}, started {state.get('started')}): "
                          f"the output may be incomplete. Run `python -m goldsluice run {self.spec.path}` again to finish it", stacklevel=2)
        events = _parquet.read(out, detector=detector if detector is not None else self._detector())
        table = self.spec.run_metadata() if metadata else None
        if table is None:
            return events
        try:
            columns = _runmeta.per_event(events.quantities["series"].to_list(), table)
        except KeyError as e:
            raise KeyError(f"{e.args[0]} (run metadata {self.spec.metadata})") from None
        clash = sorted(set(columns) & set(events.quantities.fields))
        if clash:
            raise ValueError(f"{self.spec.path}: the run metadata column(s) {clash} have the name of a column of the processed data; rename them in the table")
        return events.with_quantities(**columns)



    def _detector(self) -> Optional[str]:
        names = {s.detector for s in self.spec.sources}
        return next(iter(names)) if len(names) == 1 else None

    def iter_events(self, source: Optional[str] = None, *, processed: bool = True) -> Iterator[Events]:
        """One `Events` per raw file of `source`: its pulses, with the processed quantities attached unless `processed=False`."""
        src = self.spec.source(source)
        table = self.processed(detector=src.detector) if processed else None
        for path in src.files():
            for ev in read_raw(src, path):
                if table is not None:
                    have = set(ak.fields(ev.quantities))                  # what the adapter already gives (trigger_type, ...) is not attached again
                    extra = [f for f in ak.fields(table.quantities) if f in _rq.KEY_COLUMNS or f not in have]
                    try:
                        ev = _rq.attach(ev, table.quantities[extra])
                    except ValueError as e:
                        raise ValueError(f"{path}: {e}; has the batch run covered this file? "
                                         f"`python -m goldsluice run {self.spec.path}`") from None
                yield ev
