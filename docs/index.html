Student guides

Routine maintenance: keep your setup up to date

The project keeps changing: new releases bring new code and guides, and sometimes a new version of Python or of the packages the notebooks use. Every time the project lead announces a new release, and whenever the environment check warns you, follow Updating your setup (student guide 7). It takes about 10 minutes. Your first-analysis notebook runs the check for you; you can also run it yourself with python check_environment.py in the python folder.

Analysis Notes

Each note summarizes one investigation, pins the notebooks it rests on to the commits that produced the results, and ends with a status and next steps. Newest first. The links in a note show each file as it was at the commit named in the link, which may be older than the latest version, and the file may have moved since. To find where a file is now, see the table in data_analysis/README.md.

Status legend

StatusDefinition
CompleteNote is in a complete and finalized state.
In-progressNote is still being worked on.
Superseded (reference/link)A newer note has taken its place. This note stays up for reference and links to the newer one.
AbandonedNote was created, but, for whatever reason, is left incomplete without the intent for completion in the future.
BrainstormNote is used for brainstorming or putting down ideas, without any analysis results or conclusions.

Notebooks and deprecation

Notes marked Complete are left as they are, apart from small updates where a change in the python/ library requires one, such as a renamed function. The Jupyter notebooks they rest on are handled separately: when a library change breaks a notebook, it is either updated for the change or, if it no longer runs and is not worth fixing, marked deprecated with a warning cell at the top, like this:

Example of the marker (illustrative only; no notebook is marked deprecated at present):

DeprecationWarning: example_notebook.ipynb is deprecated (2026-09-25).
  It no longer runs: excursion_band(low, high) was renamed ratio_band in python/pulse_cuts.py.
  Kept as a record of the analysis; the current version is in Note 2.
