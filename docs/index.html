NSDF-Data Analysis Notes

Analysis of University of Minnesota R68/R76 SuperCDMS-type data accessed through the National Science Data Fabric and nsdf-cli.

GitHub repository python/ pulse library NSDF-SLAC documentation

Analysis Notes

Each note summarizes one investigation, pins the notebooks it rests on to the commits that produced the results, and ends with a status and next steps. Newest first.

Status legend

StatusDefinition
CompleteNote is in a complete and finalized state.
In-progressNote is still being worked on.
OutdatedNote is no longer relevant to the analysis or a newer version has taken its place.
AbandonedNote was created, but, for whatever reason, is left incomplete without the intent for completion in the future.
BrainstormNote is used for brainstorming or putting down ideas, without any analysis results or conclusions.

Notebooks and deprecation

Notes marked Complete are left as they are, apart from small updates where a change in the python/ library requires one, such as a renamed function. The Jupyter notebooks they rest on are handled separately: when a library change breaks a notebook, it is either updated for the change or, if it no longer runs and is not worth fixing, marked deprecated with a warning cell at the top, like this:

Example of the marker (illustrative only; no notebook is marked deprecated at present):
